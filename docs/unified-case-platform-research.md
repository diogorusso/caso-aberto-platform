# Um arquivo de casos — extensão sobre plataformas

O catálogo do CasoAberto usa um registro central de categorias para permitir busca sobre todas as investigações documentadas. A pesquisa de plataformas cobre uma questão abrangente: Meta, anúncios e decisões de moderação no Brasil durante 2026.

O registro PLAT-2026-CASE é uma **porta de entrada para o ledger de 25 evidências** em src/data/platform-observatory.json, preservadas no observatório em /observatorio/plataformas/. Os eventos não são tratados como contratos individuais ou condenações diferentes: fazem parte de uma única investigação documental com classes de evidência separadas.

Total após a integração: 17 casos (1 Florense em destaque, 8 estudos de consumo, 7 investigações de política e direitos e 1 investigação de plataformas), 12 histórias ligadas a casos e 6 categorias. Fontes, datas, etapas processuais e respostas pertencem aos seus registros originais. O playbook educacional integral permanece privado.

A voz pública segue a skill casoaberto-pt-br-tom em toda a navegação: pergunta incisiva, fonte, consequência, cobrança e CTA. Não criar divisões artificiais de casos nem disclaimer legal por conta do agente.

Qualidade: npm run verify:case-catalog, npm run verify:data, npm run check e npm run build.
